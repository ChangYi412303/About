* **身份**：獨立創作者、思維造局者。致力於解構流傳千年的東方與傳統觀念，協助人們重新拿回思考的自主權。

## 核心方法論：海綿體循環與極簡原則

我以一套持續運作的閉環推進工作與創作：

* **海綿體持續進化循環**：持續 **吸收**（新知識、跨領域經驗）→ **消化**（理解與內化）→ **輸出**（實踐與創作）→ **修正**（根據現實回饋調整）→ **再吸收**。這套模式已在現實中實踐數十年。
* **能簡單化的事情，絕對簡單化**：複雜留在內核，對外交付維持極簡。不眷戀過去、不焦慮未來，將執行聚焦於當下這一秒，讓時間成為最穩固的合夥人。

## 核心作品陣列：《枍奭》

本品牌與核心內容於 **2026年11月11日** 正名為 **《枍奭》**。取材自人生上半場的實際經驗與東方心裡學取向，透過數位作品協助讀者處理掛在心頭上的真實問題：

1. **2026年9月底推出《枍奭心裡學》**：思想、觀點與現實觀察，重新檢視人類長期形成的思考方式、價值觀與認知架構。
2. **2026年10月底推出《枍119闁》**：生活應變與實用急救工具包，將觀念更新轉化為可立即操作的判斷方法。
3. **預計2027年01月底推出《枍奭長篇小說》**：透過人物、經歷與故事，呈現舊觀念與新環境之間的衝突及人性選擇。
